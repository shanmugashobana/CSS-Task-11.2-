# Web Development Workshop - Event Registration Page

A responsive registration form page built with HTML and CSS.

## Features

- Two-column layout: illustration on the left, form on the right
- Input fields with Font Awesome icons
- Required fields marked with a red asterisk
- Submit and Cancel buttons
- Nunito font from Google Fonts

## Built With

- HTML5
- CSS3 (Flexbox)
- Font Awesome 7
- Google Fonts (Nunito)
